# PhotoTrust — проверка подлинности фото в объявлениях (прототип Gate 3)

Учебный проект курса «Управление ML-продуктами» (Центральный университет). B2B-сервис для классифайдов: каждое
фото объявления проверяется **до публикации** двумя ML-сигналами, а слой решений выбирает одно из действий:
*опубликовать сразу*, *предложить метку «Иллюстрация (ИИ)»*, *отправить модератору* или *скрыть и отправить модератору*.
Модель никого не блокирует сама.

| Сигнал | Модель | Бейзлайн |
|---|---|---|
| **Копия** чужого фото (в том числе изменённая) | [SSCD](https://github.com/facebookresearch/sscd-copy-detection) (Meta, CVPR 2022) + поиск ближайших соседей; для сравнения DINOv2 ViT-S/14 | pHash |
| **ИИ-генерация** | [UniversalFakeDetect](https://github.com/WisconsinAIVision/UniversalFakeDetect) (CLIP ViT-L/14 + линейный слой, CVPR 2023) | — |

## Результаты (категория «Электроника», Shopee)

**Сигнал «копия»** — база из 4 579 фото (1 579 фото электроники + 3 000 фото других категорий).
Порог выбирается по доле честных фото того же товара, которые уйдут модератору (FPR).

| Метод | Исходное фото на 1-м месте | Recall при FPR 1% (синт. / реальные) | Recall при FPR 5% (синт. / реальные) |
|---|---|---|---|
| pHash (бейзлайн) | 38% | 31% / 47% | 34% / 59% |
| DINOv2 | 88% | 35% / 56% | 58% / 82% |
| SSCD (320×320) | 93% | 47% / 64% | 63% / 81% |
| **SSCD-288** (выбран) | **93%** | 45% / 61% | **68% / 81%** |

* *синт.* — 2 200 копий: 200 фото × 11 «мошеннических» изменений (`src/photo_trust/attacks.py`);
* *реальные* — 186 настоящих перезаливов чужого фото в Shopee (тот же снимок с чужим логотипом, рамкой, кропом),
  найденных ручной разметкой 390 пар (`annotations/manual_review_labels.csv`);
* честные фото — 421 фото того же товара, но другой снимок (после ручной проверки).

SSCD выигрывает у pHash там, где pHash ломается: кроп 80% (0,90 против 0), отражение (0,96 против 0), рамка
(0,84 против 0,10), скриншот объявления (0,80 против 0). **Не ловит никто:** кроп 55%, поворот, комбинация
изменений — это задача дообучения на Gate 4. Детали: `results/copy_*.csv`, `results/fig_*.png`.

**Сигнал «ИИ»** — 160 реальных фото Shopee, те же 160 после «улучшайзера», 59 ИИ-фото товаров от генераторов
2026 года (Gemini 3.1 Flash Image, gpt-image-2):
ROC-AUC 0,84; при FPR 5% на реальных фото детектор находит лишь 24% ИИ-фото, на отредактированных реальных
фото даёт 8,8% ложных срабатываний. Вывод: сигнал годится только как подсказка / добровольная метка.

**Скорость** (i5-11300H, 4 потока / RTX 3050 Ti Laptop):

| Этап | CPU p50 / p95 | GPU p50 / p95 |
|---|---|---|
| pHash | 2 / 4 мс | — |
| SSCD-288 | 119 / 134 мс | 18 / 22 мс |
| Детектор ИИ | 863 / 911 мс | 93 / 93 мс |
| Точный поиск FAISS, 100 тыс. / 1 млн векторов | 11 / 110 мс | — |

## Как запустить

```bash
pip install -r requirements.txt          # для GPU поставьте сборку torch с CUDA
```

1. **Данные Shopee** (условия соревнования Kaggle, в репозиторий не входят): скачайте
   <https://www.kaggle.com/competitions/shopee-product-matching/data> и распакуйте в `data/shopee/`
   (`train.csv`, `train_images/`).
2. **ИИ-фото** (CC0): `python scripts/download_ai_images.py --per-category 40`.
3. Пайплайн:

```bash
python scripts/build_eval_sets.py          # база, 11 атак, честные фото
python scripts/eval_copy.py                # pHash vs SSCD vs SSCD-288 vs DINOv2 (кэш эмбеддингов в cache/)
python scripts/make_review_grids.py        # сетки для ручной разметки (метки уже в annotations/)
python scripts/eval_ai.py                  # детектор ИИ
python scripts/benchmark.py                # скорость моделей (CPU или CUDA)
python scripts/benchmark_faiss.py          # скорость поиска
python scripts/pick_demo_examples.py && python scripts/make_figures.py
streamlit run app.py                       # демо
```

Веса моделей скачиваются автоматически с CDN Meta / OpenAI / GitHub в `models/`.

## Структура

```
src/photo_trust/   attacks.py · embedders.py · ai_detector.py · decision.py · data.py · config.py
scripts/           сборка наборов, оценка, бенчмарки, графики
app.py             Streamlit-демо: фото → совпадения + скоры + решение
annotations/       ручная разметка «то же фото / другое фото»
results/           метрики (json/csv) и графики
```

## Ограничения

* Shopee — e-commerce Юго-Восточной Азии, а не классифайд РФ; меток «мошенничество» нет — копии синтетические
  или найденные ручной разметкой одним человеком.
* ИИ-фото отличаются от реальных ещё и сюжетом (повреждённые товары), что может завышать ROC-AUC.
* Продавцы и цены в демо синтетические — в Shopee их нет.
